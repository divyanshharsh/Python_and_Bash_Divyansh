## Assignment Objectives

The assignment focuses on practicing basic Python programming concepts, including:

- Conditional statements
- Dictionaries
- User input
- Loops
- File handling
- Reading and writing text files

## Tasks Completed

### 1. Grade Checker

The `grade_checker.py` program accepts a score from the user and determines the grade based on the following criteria:

| Score | Grade |
|---|---|
| 90+ | A |
| 80–89 | B |
| 70–79 | C |
| 60–69 | D |
| Below 60 | F |

The program uses `if`, `elif`, and `else` conditional statements.

### 2. Student Grade Manager

The `student_grades.py` program uses a Python dictionary to store student names and their grades.

The program allows the user to:

- Add a new student
- Update an existing student's grade
- Display all student grades
- Exit the program

It also uses conditional statements, loops, dictionary operations, and user input.

### 3. Write to a File

The `file_write.py` program demonstrates Python file handling.

It uses:

- `open()`
- Write mode (`"w"`)
- `write()`

The program creates a text file and writes content into it.

### 4. Read from a File

The `file_read.py` program reads the content of the text file created in the previous task.

It uses:

- `open()`
- Read mode (`"r"`)
- `read()`

The file content is then displayed in the terminal.
